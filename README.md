# SAQ · Кадры

Интерактивный макет внутреннего обучения сотрудников. Создан по результатам обследования `lms.obu.gov.kz` от 13.10.2026; структура React/TypeScript и оформление согласованы с `ewgftju/saq-prof-control-demo`.

**Текущая версия — функциональный frontend-макет, а не промышленная LMS.** Данные и результаты сохраняются в браузере; файлы — в IndexedDB. Переключатель ролей предназначен для демонстрации и не заменяет серверную авторизацию. Между устройствами данные не синхронизируются. В репозитории нет учётных данных исходной LMS, её пользовательской базы и учебных файлов.

## Запуск

Требуется Node.js 22.12+ или 24.

```bash
npm ci
npm run dev
npm run typecheck
npm test
npm run build
```

Frontend расположен в `hr_frontend`. Сборка: `hr_frontend/dist`.

## Что можно сделать

- Кадровая служба: вести сотрудников, создавать курсы и программы, добавлять учебные файлы и ссылки, назначать обучение сотрудникам и подразделениям со сроком.
- Конструктор тестов: один или несколько правильных ответов, краткий ответ, открытый ответ; баллы, проходной процент, лимит времени и попыток, перемешивание, выборка вопросов, импорт JSON/CSV.
- Сотрудник: открыть назначенный курс, изучить уроки, пройти итоговый тест, посмотреть результаты и получить печатный сертификат при завершении курса.
- Кадровая служба: видеть прогресс и баллы каждого сотрудника, проверять открытые ответы, фильтровать результаты и выгружать CSV.
- Библиотека: документы, НПА, аудио и внешние материалы. Уведомления о назначениях и результатах доступны через колокольчик.

## Сценарий демонстрации

1. Откройте «Назначения» в режиме «Кадровая служба», выберите сотрудника, опубликованный курс и срок.
2. Переключитесь в «Сотрудник» и выберите того же человека в шапке.
3. В «Моё обучение» откройте курс и последовательно отметьте изученные материалы.
4. Пройдите итоговый тест. Открытые ответы останутся «На проверке» до оценки кадров.
5. Вернитесь в кадровый режим. В «Результаты и отчёты» проверьте попытку; в карточке сотрудника проверьте изменившийся прогресс.
6. Обновите страницу: назначения, результаты, ответы текущей попытки и загруженные файлы сохраняются в этом браузере.

Демонстрационные учебные тексты и вопросы созданы специально для макета; они не являются нормативной базой или утверждённым экзаменом. Вопросы для боевого обучения загружаются кадровой службой.

## Публикация на Vercel

В репозитории есть `vercel.json`. Импортируйте этот GitHub-репозиторий, оставьте корневую папку проекта, команду сборки `npm run build`, каталог результата `hr_frontend/dist`. Переменные окружения для макета не нужны. SPA-переходы настроены. Публикация на Vercel в рамках этой версии не выполнялась.
