# Проверки версии

## Среда и объём

- Node.js 24, TypeScript strict, Vite production build.
- Vitest: чистые доменные правила и взаимодействие React-компонентов в jsdom.
- Файловое хранилище: IndexedDB API через fake-indexeddb с повторным открытием хранилища.
- Обследование исходной LMS выполнено через её реальный веб-интерфейс после входа пользователя.

## Проверенные сценарии

1. Кадры назначают курс выбранному сотруднику через форму. Другой сотрудник не получает назначение.
2. Сотрудник открывает курс, завершает урок и перезагружает интерфейс — прогресс сохраняется.
3. До завершения уроков итоговый тест недоступен.
4. Начатая попытка, ответы и исходное время окончания сохраняются при повторном открытии.
5. Результат успешного теста отражается в кадровом журнале и сохраняется после перезагрузки.
6. Открытые ответы ждут ручной проверки; оценка кадров завершает попытку.
7. Сотруднику запрещены кадровые команды и прохождение чужого назначения.
8. Прямые переходы на закрытые кадровые маршруты переводят сотрудника в своё обучение.
9. Импорт невалидных JSON/CSV отклоняется; корректный импорт создаёт редактируемый тест.
10. Неверные ответы, штрафы, несколько вариантов и краткие ответы оцениваются согласно настройкам.
11. Пограничный балл сравнивается без округления; неуспешный тест не выдаёт сертификат.
12. Перемешанная попытка хранит независимый снимок вопросов; редактирование теста не меняет уже начатую попытку.
13. Просроченная попытка использует сохранённые ответы, поздние ответы отклоняются.
14. Нулевые лимиты поддерживают тест без ограничения времени и числа попыток.
15. Повторная отправка завершённой попытки не создаёт новую оценку.
16. Повреждённая структура состояния отклоняется; CSV экранирует потенциальные формулы.
17. Загруженный файл сохраняет байты и MIME при повторном открытии IndexedDB; удаление работает. Файл больше 50 МБ и недоступное хранилище возвращают понятную ошибку.

## Ограничения проверки

Сборка и 19 автоматических тестов не заменяют промышленную приёмку. Проверка экранов нового модуля выполнена на уровне DOM-сценариев и CSS/TypeScript; визуальный прогон в реальном браузере и на опубликованном Vercel-адресе ещё не выполнялся. Серверная авторизация, многопользовательская БД, SSO, внешние ИИ-сервисы, email и подлинность сертификата не подключены и не проверялись.
